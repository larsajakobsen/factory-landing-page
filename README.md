# factory-landing-page

## Running the page

### View the page
Open `index.html` in a web browser, or serve it locally. Pages: `index.html` (landing page) and `om-nova-consulting-group.html` (About Nova Consulting Group), with `404.html` shown for missing pages.
```bash
python3 -m http.server
# Then open http://localhost:8000
```

### Run tests
```bash
node --test tests/
```
Requires Node.js. No `npm` or external packages needed.

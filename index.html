What is Agent Factory?

Agent Factory is a hosted software factory from Nova Consulting Group that turns GitHub issues into reviewed pull requests. It automates the full development pipeline, from issue intake through human review, so your team can focus on decisions, not execution.

How it works

  1. Intake: a GitHub issue with acceptance criteria
  2. Plan: analyse the repository and write an implementation plan
  3. Implement: make the smallest complete change
  4. Test: add or update tests and run build and test
  5. Review: an automated critical review of the diff
  6. Pull request: open a PR linked to the issue
  7. Human review and merge: your team reviews and merges

What makes it ours

  • Versioned factory policy: the rules the factory follows are versioned
  • Project profile: per-project configuration of build, test and conventions
  • Oslo Live benchmark: the factory is measured against the Oslo Live benchmark

What you see

  • Control UI: follow runs and their status
  • Cost per merged PR: a transparent cost metric

Where it runs

Each customer gets an isolated instance. The MVP runs in Nova's Azure tenant. Customer-hosted deployment comes later.

MVP and timeline

The MVP takes 7 weeks. The pilot is evaluated against agreed success criteria, such as merged PRs and cost per merged PR.

Chat-based intake, Azure DevOps support and customer-hosted deployment are planned for later.
